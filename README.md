# Uzay Savaşı

Bu repo Unity ile yapılmış kısa bir egzersiz çalışmasıdır,  yayınlanabilir veya bitmiş bir oyun olarak düşünülmemelidir.

Çalışmada uzay savaşı temalı basit bir sahne, oyuncu gemisi hareketi, lazer atışı, sınır kontrolü, prefablar, modeller, materyaller ve ses dosyaları bulunur. Proje; Unity sahne yapısı, fizik tabanlı hareket, input kullanımı ve temel prefab akışını denemek için hazırlanmıştır.

## Unity Sürümü

Unity 6000.1.1f1
